# Claude Codeフック設定

このディレクトリには、Piaryプロジェクト固有のClaude Codeフック設定が含まれています。

## 概要

記事 https://zenn.dev/sesere/articles/e3d5695e0a7d14 を参考に、プロジェクト固有の「ガードレール」を設定し、Claude Codeが不適切な操作や回答を行うことを防ぎます。

## フォルダ構造

```
.claude/
├── settings.json                    # メインのフック設定
├── hooks/
│   ├── README.md                   # このファイル
│   ├── hook_stop_words.sh          # ストップワードフック
│   ├── hook_pre_commands.sh        # コマンド実行前フック
│   └── rules/
│       ├── hook_stop_words_rules.json      # ストップワードルール定義
│       └── hook_pre_commands_rules.json    # コマンド実行前ルール定義
```

## フック機能

### 1. ストップワードフック (`hook_stop_words.sh`)

**目的**: Claude Codeの回答内容をチェックし、不適切な表現を検出する

**チェック対象**:
- 推測的な候補の提示（「以下の候補が考えられます」など）
- 代替案の提示（「別の方法として」など）
- 要求されていない改善提案
- 追加機能の提案
- 推測的な表現（「かもしれません」など）

**動作**:
- Claude Codeの回答が生成される前に実行
- 禁止パターンが検出された場合、エラーメッセージとともに処理を停止

### 2. コマンド実行前フック (`hook_pre_commands.sh`)

**目的**: Bashコマンドの実行前にセキュリティチェックを行う

**チェック対象**:
- 危険なコマンド（`rm -rf /`、`sudo rm`など）
- セキュリティリスクのあるコマンド（`chmod 777`など）
- 不明なスクリプトの実行（`curl | sh`など）
- 許可リストにないコマンド

**動作**:
- Bashツールの実行前に実行
- 危険なコマンドは実行を停止
- 許可リストにないコマンドは警告表示
- 重要な操作（DBマイグレーションなど）は確認メッセージ表示

## プロジェクト固有のルール

### 許可されているコマンド
- `pnpm`, `npm`, `yarn` - パッケージマネージャー
- `dotnet` - .NET CLI
- `git` - バージョン管理
- `ls`, `cat`, `head`, `tail` - ファイル操作
- `grep`, `rg` - 検索
- `find`, `mkdir`, `cp`, `mv` - ファイルシステム操作

### 特別な扱いのコマンド
- `pnpm generate` - TypeSpecコード生成（自動許可）
- `pnpm db:migration:*` - DBマイグレーション（確認メッセージ表示）

## カスタマイズ

### ストップワードルールの追加

`rules/hook_stop_words_rules.json`に新しいルールを追加：

```json
{
  "pattern": "新しい正規表現パターン",
  "error_message": "表示するエラーメッセージ"
}
```

### コマンドルールの追加

`rules/hook_pre_commands_rules.json`に新しいルールを追加：

```json
{
  "pattern": "^新しいコマンドパターン",
  "error_message": "表示するエラーメッセージ"
}
```

## トラブルシューティング

### フックが動作しない場合

1. スクリプトファイルの実行権限を確認:
   ```bash
   chmod +x .claude/hooks/*.sh
   ```

2. `jq`コマンドがインストールされているか確認:
   ```bash
   which jq
   ```

3. JSONファイルの構文エラーをチェック:
   ```bash
   jq . .claude/hooks/rules/*.json
   ```

### フックを無効にする場合

`.claude/settings.json`から該当するフック設定を削除またはコメントアウトしてください。

## 注意事項

- フックスクリプトは慎重に編集してください
- 新しいルールを追加する際は、必要最小限に留めてください
- フックが過度に制限的になると開発効率が下がる可能性があります
- 定期的にフックの効果を確認し、必要に応じて調整してください
